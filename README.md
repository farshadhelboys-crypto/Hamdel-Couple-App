# همدل (Hamdel) 💕

اپلیکیشن عاشقانه دونفره — امتیاز روزانه، احساسات و همگام‌سازی آنلاین با Cloudflare Workers.

## امکانات
- ساخت اتاق با کد ۶ رقمی و وصل شدن دو گوشی
- امتیازدهی ستاره‌ای + کامنت به عشق
- تیک زدن احساسات (ناراحت شدم، روز خوبی بود، دلم تنگه، …)
- دریافت پیام در گوشی دوم + نوتیفیکیشن
- UI عاشقانه تیره با انیمیشن قلب

## راه‌اندازی Worker (Cloudflare)

1. یک Worker جدید بسازید و محتوای `worker/worker.js` را پیست کنید.
2. یک دیتابیس D1 بسازید و به Worker بایند کنید با نام `DB`.
3. یک بار `POST /api/setup` بزنید تا جداول ساخته شوند.
4. آدرس Worker را در `HamdelApp.kt` داخل ثابت `API_BASE` قرار دهید.

## ساخت APK
GitHub Actions روی پوش `main` به‌صورت خودکار APK می‌سازد.
Artifact: **Hamdel-apk**

## استفاده
1. نفر اول: اسمش را وارد کند → «ساختن اتاق» → کد را به عشق بدهد
2. نفر دوم: همان کد را وارد کند → «وصل شدن»
3. هر دو می‌توانند امتیاز و احساس بفرستند و در تب «دریافتی» ببینند
